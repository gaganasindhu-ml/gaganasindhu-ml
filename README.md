## 📊 Signature Projects — Deep Dive

### 🛡️ FraudShield — Healthcare Fraud Detection
> **Problem:** US healthcare loses $1B+ annually to fraudulent provider claims
- Merged 8 datasets across beneficiary, inpatient, outpatient, and provider records
- Handled severe class imbalance (9:1) using SMOTE
- Engineered 17 fraud-signal features: claim-to-provider ratio, chronic condition flags, physician anomaly scores
- SHAP explainability — model explains WHY a claim is flagged, not just that it is
- **Result:** 94.2% accuracy · Deployed as interactive Streamlit app

### 🔗 Chainsight — Supply Chain Delay Prediction
> **Problem:** Supply chain disruptions cost companies 6-10% of annual revenue
- Features engineered from real-world factors: route type, weather severity, geopolitical risk, logistics cost
- Compared 5 models: XGBoost, Random Forest, SVM, KNN, Logistic Regression
- Full EDA pipeline with feature importance analysis
- Deploy-ready saved model with Streamlit UI

### 🛍️ ShopIQ — AI Customer Segmentation
> **Problem:** Businesses waste marketing spend targeting the wrong customers
- K-Means clustering to identify distinct customer segments
- Isolation Forest for anomaly/outlier customer detection
- Actionable segment profiles for marketing strategy
